# Contributing to Advectra.jl

Thank you for your interest in contributing to Advectra.jl! Bug reports, feature requests,
documentation improvements and pull requests are all welcome.

## Code of conduct

We want Advectra.jl to be a welcoming and respectful community for everyone. By
participating in this project you agree to:

- Be respectful and considerate towards others, regardless of background, identity or
  level of experience.
- Give and receive constructive feedback gracefully, focusing on the work rather than the
  person.
- Refrain from harassment, personal attacks, discriminatory language or any other
  unwelcoming behaviour.

Unacceptable behaviour may be reported to the maintainer at
johannes.e.morkrid@uit.no. Maintainers may remove, edit or reject comments, commits,
issues and pull requests that do not follow this code of conduct.

## Reporting issues

Please report bugs and request features through
[GitHub Issues](https://github.com/JohannesMorkrid/Advectra.jl/issues). When reporting a
bug, include a minimal example that reproduces the problem, the expected behaviour, and
your Julia and Advectra.jl versions.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Make your changes, adding tests and documentation where appropriate.
3. Make sure the test suite passes (`] test Advectra`).
4. Open a pull request describing what you changed and why.

Please follow the [style guide](docs/src/style-guide.md)
when writing code and docstrings.
